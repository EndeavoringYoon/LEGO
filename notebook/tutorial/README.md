# LEGO Tutorial

End-to-end walk-through of the LEGO pipeline:
**Data preprocessing → Latent space learning → VOO optimization → Analysis**

Paper: [arXiv:2604.08636](https://arxiv.org/abs/2604.08636): "LEGO: Latent-space Exploration for Geometry-aware Optimization of Humanoid Kinematic Design" (ICRA 2026)

---

## 🛡️ Safety conventions

Every notebook starts with:

```python
SAVE_OUTPUTS = False        # default: read canonical, never overwrite
SKIP_TRAINING = True        # default: load pretrained model from canonical/model_dir
RUN_FULL_VOO = False        # default: single-run demo only

TUTORIAL_OUT = './outputs/'
CANONICAL    = './canonical/'
```

| Variable | Effect when True |
|---|---|
| `SAVE_OUTPUTS` | Writes intermediate artifacts to `outputs/` (never to project canonical paths) |
| `SKIP_TRAINING` | Section 1 loads pretrained model from `canonical/model_dir/model.pt` instead of training |
| `RUN_FULL_VOO`  | Section 2 launches 10×3 motion × 3-method full reproduction (≈3-5h CPU) instead of single demo |

**Hard rules**: the tutorial NEVER writes to
- `data/mjcf_test/`
- `result/h64_32_z2_isoTrue.../`
- `notebook/ae_test/*_motion_*/`, `notebook/ae_test/all_*/`

Only `outputs/` inside this tutorial folder is writable.

## 🚀 Quick start

```bash
conda activate lego      # see the top-level README for installation

# Launch jupyter from project root
cd LEGO   # repository root
jupyter lab notebook/tutorial/
```

Recommended reading order:
1. `01_latent_space_learning.ipynb`: most self-contained (~2 min run)
2. `03_analysis_visualization.ipynb`: read-only over canonical results (~10 min)
3. `02_design_optimization_voo.ipynb`: single VOO demo (~5 min with the default `easy` motion)
4. `05_retarget_to_designed_robot.ipynb`: turn the optimized design into a moving robot (~1 min)
5. `00_data_preprocessing.ipynb`: most niche, last (~5 min)

## ⚙️ Requirements

```
conda env:        see top-level README (Python 3.10, requirements.txt)
python packages:  mujoco 3.x, torch, scipy, numpy, matplotlib, moviepy, opencv-python, PyQt5
headless:         MUJOCO_GL=osmesa (or egl), or xvfb-run, for the offscreen rendering in 04 and 05
canonical model:  result/h64_32_z2_isoTrue_actvTanh_isoreg1e-07_nepoch1000_bs10/model.pt (must exist)
canonical data:   data/mjcf_test/{screw,dh}/data.npy + njnt.npy + label.npy (must exist)
BVH motions:      bvh/cmu_mocap_full_dataset/cmu_bvh/data/{141/141_16, 018/18_15, 079/79_02}.bvh
SMPL (optional):  data/smpl_model/model.pkl + an MDM *_smpl_params.npy, only with MOTION_SOURCE = 'smpl' (02, 05)
```

SMPL motions (e.g. generated by MDM) go through the same retargeting as the BVH files. Neither the
SMPL model nor the motions are included; `05_retarget_to_designed_robot.ipynb` §7 explains how to
obtain them.
